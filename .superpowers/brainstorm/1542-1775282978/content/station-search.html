How do users find stations?

Adding a station requires a siteId (e.g. 9324 for Duvbo). Users won't know these IDs.

A

Live search via SL API

Type a station name → hits transport.integration.sl.se/v1/sites/?q=duvbo → shows matching stations with their IDs. One-click to add.

Pros

  • Find any station in Stockholm
  • No manual ID lookup

Cons

  • Requires API call during configuration
  • Need to handle what modes a site has (not all sites have all modes)
B

Manual entry

User types the site ID directly. They find it from the SL API docs or by inspecting the dashboard URL after using option A elsewhere.

Pros

  • Zero extra API calls
  • Trivial to build

Cons

  • Requires users to know their site ID — not beginner-friendly
