Where does the URL creator live?

The dashboard is deployed at a fixed URL. Users configure it via query parameters. Where should the configuration UI appear?

A

Separate page at /configure

A dedicated configuration page. You build your station list there, copy the generated URL, and open it as a new tab. The dashboard itself is unchanged.

Pros

  • Clean separation — dashboard stays fast and focused
  • Easy to share the configurator URL with others

Cons

  • Context switch — you build config elsewhere and paste into a new tab
B

Overlay / modal on the dashboard

A settings icon on the dashboard opens a panel. You edit, click "Apply", and the page reloads with the new URL. Never leaves the dashboard.

Pros

  • Seamless — configure and see results in one place

Cons

  • Adds UI chrome to a display that's meant to be clean and always-on
C

Separate app / standalone HTML file

A completely independent configurator.html served alongside the dashboard. No routing needed — just open it separately to build your URL.

Pros

  • Simplest to build — no routing, no React Router needed
  • Zero impact on dashboard bundle size

Cons

  • Two separate codebases / entry points to maintain
